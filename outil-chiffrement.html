Outil de chiffrement de l’espace JSP

Cet outil fabrique la version protégée par mot de passe de l’espace JSP, avec les documents PDF à l’intérieur. Tout se passe sur ton ordinateur : rien n’est envoyé sur internet.

Étape 1 : choisis la page de l’espace JSP

C’est le fichier espace-jsp.html du dossier prive (celui que tu modifies).

Étape 2 : choisis tes documents PDF (facultatif)

Ouvre le dossier prive/docs, sélectionne tous les PDF d’un coup (Ctrl + A), puis valide. Leur nom doit être le même que dans la page.

Étape 3 : choisis le mot de passe

C’est le mot de passe que les jeunes taperont pour entrer. Écris-le deux fois.

Conseil : plus il est long, plus il est solide. Un mot de passe court comme 123 se devine en quelques secondes : prends-le seulement pour tester.

Ensuite

Le fichier espace-jsp.html est téléchargé. Mets-le à la racine du dépôt GitHub (à côté de index.html) : il remplace l’ancien. Ne publie jamais le dossier prive.
